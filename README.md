# Учебный проект: Pharmacy — информационная система управления аптекой
## Разработчик: Земдиханова Амина 4ИСИП-523

**Pharmacy** — настольное приложение для автоматизации управления сетью аптек и лекарственными запасами, разработанное на C# с использованием WPF и Microsoft SQL Server.

Система предназначена для организации учёта товаров, управления поставками, контроля складских остатков и проведения инвентаризации. Приложение объединяет основные процессы работы аптеки и обеспечивает хранение информации в единой базе данных.

Проект разработан в рамках учебной практики по специальности 09.02.07 «Информационные системы и программирование».

## Основной функционал

### 1. Авторизация и управление пользователями

Система предусматривает вход пользователей в приложение и разграничение доступа в зависимости от их ролей. Это позволяет разделять полномочия сотрудников и пользователей, отвечающих за управление аптекой.

В разделе пользователей предусмотрен просмотр информации о зарегистрированных пользователях и добавление новых сотрудников. Данные о пользователях связаны с их ролями и используются для организации доступа к функциям системы.

### 2. Управление товарами

Раздел товаров предназначен для просмотра и поиска продукции, зарегистрированной в базе данных. Для удобства работы предусмотрены поиск по названию, фильтрация по категориям и сортировка списка товаров.

Для каждого товара хранится основная информация, включая наименование, цену и изображение. Данные о товарах используются в других разделах системы, в частности при оформлении поставок и учёте складских остатков.

### 3. Учёт аптек

Система поддерживает хранение информации об аптеках и организацию работы пользователей с соответствующими торговыми точками.

Связи между пользователями и аптеками позволяют учитывать место работы сотрудников, а также предусматривать работу ответственных лиц с несколькими аптеками. Учёт по отдельным аптекам необходим для корректного отображения наличия продукции и проведения инвентаризации.

### 4. Управление поставками

Функционал поставок предназначен для регистрации поступления товаров и отражения их количества в учётной системе.

При оформлении поставки указываются необходимые сведения о поступлении, включая дату, ответственное лицо, аптеку или место хранения, а также состав поставки. Для каждого добавленного товара задаётся количество. На основании состава поставки может рассчитываться её общая стоимость.

Информация о поставках сохраняется в базе данных и используется для ведения учёта поступившей продукции.

### 5. Учёт складских остатков

Система предусматривает хранение сведений о количестве товаров и их наличии в аптеке. Учёт продукции позволяет отслеживать движение товаров и сопоставлять фактические остатки с данными информационной системы.

Для отдельных единиц или партий продукции могут храниться дополнительные характеристики, включая серию и срок годности. Это позволяет учитывать особенности хранения лекарственных средств и контролировать информацию о конкретных партиях товара.

### 6. Проведение инвентаризации

Инвентаризация предназначена для проверки соответствия фактического количества товаров данным складского учёта.

В ходе инвентаризации фиксируются товары, их учётное и фактическое количество. На основании этих значений определяется расхождение между данными системы и результатами фактической проверки. Это позволяет выявлять недостачи и излишки и получать более точную информацию о состоянии запасов.

Результаты инвентаризации сохраняются в базе данных. Предусмотрена работа с историей ранее проведённых проверок, что позволяет просматривать сохранённые результаты и обращаться к информации о конкретной инвентаризации.

### 7. Формирование и экспорт отчётов

Для работы с результатами инвентаризации предусмотрен экспорт отчётных данных в Excel или Word. Отчёт формируется на основании выбранной инвентаризации и связанных с ней записей о товарах.

Экспорт позволяет использовать результаты проверки вне приложения, сохранять их в виде отдельных документов и применять для дальнейшего анализа складских остатков.

### Пользовательский интерфейс

Приложение реализовано с использованием WPF и XAML. Интерфейс разделён на страницы, соответствующие основным направлениям работы системы.

Для оформления используются словари ресурсов, содержащие стили элементов управления и параметры внешнего вида. Предусмотрено переключение между вариантами оформления приложения, что позволяет изменять цветовую схему интерфейса.

## Структура базы данных

База данных `Pharmacy` хранит сведения, необходимые для функционирования системы. Она включает следующие основные сущности:

- `Users` — сведения о пользователях;
- `Roles` — роли пользователей;
- `Products` — информация о товарах;
- `Category` — категории продукции;
- `Pharmacies` — сведения об аптеках;
- `ProductPharmacies` — связи товаров с аптеками;
- `SpecificallyProducts` — данные об отдельных партиях продукции, включая серию и срок годности;
- `Supplies` — информация о поставках;
- `ProductsSupply` — состав поставок и количество товаров;
- `OnlineOrder` — информация об онлайн-заказах;
- `Inventory` и `InventoryDetails` — данные об инвентаризациях и результатах проверки товаров.
